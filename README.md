# CFF Ranker MVP

Open `index.html` in a browser.

Features:
- Drag-and-drop personal rankings
- Froton Rank and Yahoo ADP columns
- My Value = Yahoo ADP - My Rank
- QB/RB/WR/TE filters
- Search by player/school
- Target/Fade cycling
- Tier assignment
- Auto-save via browser localStorage
- Reset to Froton
- Export rankings to CSV

Note: The included player list is placeholder/demo data for interface testing. Replace with the verified 2026 player dataset before public launch.
